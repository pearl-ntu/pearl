# PEARL - Photon Emission and Reactivity Laboratory

Website for the Photon Emission and Reactivity Laboratory (PEARL) at Nanyang Technological University (NTU).

## Website

Visit the live site: https://pearl-ntu.github.io/pearl/

## Structure

- `index.html` - Home page
- `research.html` - Research overview
- `publications.html` - Publications list
- `people.html` - Team members
- `news.html` - News and updates
- `join-us.html` - Join us page
- `contact.html` - Contact information

## Data Files

- `publications-data.js` - Publications data
- `news-data.js` - News items
- `people-data.js` - Team member information

## Deployment

This site is deployed on GitHub Pages. Changes pushed to the `main` branch are automatically deployed.
